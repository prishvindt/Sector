# Сектор

Android-приложение 0.1.0-beta для полевой работы с GPS, ручным азимутом радиосигнала, сектором направления на карте и ручным обменом замерами через текст.

## Что умеет версия 0.1.0-beta

- Показывает Яндекс-карту и текущую GPS-позицию.
- Рисует точку, круг точности, центральную линию азимута и сектор погрешности.
- Сохраняет замеры локально в Room.
- Экспортирует последний активный свой замер в текст `SECTOR_MEASUREMENT_V1`, копирует его в буфер и открывает системный Share Sheet.
- Импортирует один текстовый замер за раз.
- Считает первое корректное пересечение центральных азимутных лучей.
- Позволяет поставить точку назначения долгим нажатием и открыть маршрут в Яндекс.Картах или попытаться построить маршрут внутри приложения.
- Проверяет обновления через GitHub-hosted `update.json`.

Приложение не содержит Firebase, Crashlytics, Google Analytics, рекламных SDK, аккаунтов и серверной синхронизации. Координаты и замеры не отправляются автоматически.

## Яндекс MapKit API key

1. Скопируйте `local.properties.example` в `local.properties`.
2. Укажите ключ:

```properties
MAPKIT_API_KEY=YOUR_KEY
```

`local.properties` добавлен в `.gitignore`; не коммитьте реальный ключ.

Если ключ пустой, приложение покажет понятную ошибку вместо падения.

## Сборка

Требуется JDK 17.

```bash
./gradlew clean
./gradlew assembleDebug
./gradlew assembleRelease
```

Имена APK:

- `Sector-0.1.0-beta-debug.apk`
- `Sector-0.1.0-beta-release.apk`

## Release signing

Keystore и пароли не хранятся в репозитории. Для локальной release-сборки можно передать переменные окружения:

- `ANDROID_KEYSTORE_PATH`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

## GitHub Actions secrets

- `YANDEX_MAPKIT_API_KEY`
- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Debug job собирается всегда. Release job запускается только когда доступны release secrets.

## Экспорт и импорт

Экспорт создаёт человекочитаемый текст с маркером `SECTOR_MEASUREMENT_V1`. Он содержит координаты, азимут, погрешность, мощность, точность GPS и время замера. Отправляйте такие данные только доверенным людям.

Импорт выполняется вручную через пункт меню "Импорт". При совпадении `measurement_id` существующий замер обновляется.

## Ограничения 0.1.0-beta

Нет сервера, аккаунтов, live-синхронизации, Bluetooth, QR-кодов, JSON-файлов экспорта, офлайн-карт, подключения к радиоприборам и автоматического расчёта расстояния по мощности.
