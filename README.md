# Сектор

Android-приложение для полевой работы с GPS, азимутными лучами, сектором погрешности, маршрутами и ручным обменом точками через текст.

## Что умеет

- Показывает Яндекс-карту и текущую GPS-позицию.
- Рисует азимутные лучи и сектор погрешности.
- Создаёт азимутный луч из текущей GPS-точки.
- Создаёт азимутный луч из произвольной точки на карте.
- Позволяет указать позывной в окне параметров азимута.
- Использует погрешность азимута 5° по умолчанию.
- Ставит точку назначения по долгому нажатию на карте.
- Строит маршрут внутри приложения.
- Открывает выбранную точку в Яндекс.Картах.
- Показывает маршрутную панель при активном маршруте.
- Показывает GPS-точку как стрелку при активном маршруте.
- Сохраняет замеры локально в Room.
- Импортирует и экспортирует замеры через текст.
- Экспортирует один или несколько азимутных лучей.
- Импортирует несколько блоков `SECTOR_MEASUREMENT_V1` из одного текста.
- Поддерживает ручной обмен текущей GPS-точкой через `SECTOR_LOCATION_V1`.
- Импортирует GPS-точки без азимута как location-only точки.
- Считает первое корректное пересечение центральных азимутных лучей.
- Проверяет обновления через GitHub-hosted `update.json`.
- Не содержит Firebase, Crashlytics, Google Analytics и автоматической серверной синхронизации.

Координаты и замеры не отправляются автоматически. Экспорт и импорт выполняются только вручную через системный обмен или вставку текста.

## Backend телеметрии

Backend технической статистики лежит в [backend/](backend/). Он предназначен для официальных и self-hosted сборок и принимает только минимальные события `app_start`, `heartbeat` и `app_background` при явном согласии пользователя.

Официальные APK могут использовать telemetry backend автора. Self-hosted сборки могут поднять свой backend и указать свой `TELEMETRY_URL` в будущей Android-задаче.

Координаты, маршруты, азимуты, замеры, позывной и контакты в telemetry backend не отправляются.

## Яндекс MapKit API key

1. Скопируйте `local.properties.example` в `local.properties`.
2. Укажите ключ:

```properties
MAPKIT_API_KEY=YOUR_KEY
```

## Экспорт и импорт

`SECTOR_MEASUREMENT_V1` описывает азимутный замер: координаты, азимут, погрешность, дальность, точность GPS, спутники, мощность, время и опциональный `colorArgb`.

Несколько блоков `SECTOR_MEASUREMENT_V1` можно отправить одним текстом. Старые блоки без `colorArgb` остаются совместимыми; цвет нужен только для сохранения цвета импортированного луча.

`SECTOR_LOCATION_V1` описывает текущую GPS-точку без азимута. Такие точки импортируются отдельно от азимутных замеров и не включаются в экспорт лучей.

Импорт выполняется вручную через пункт меню "Импорт". Координаты и замеры не отправляются автоматически.

Подробнее: [docs/EXCHANGE_FORMATS.md](docs/EXCHANGE_FORMATS.md).
